# iTask - Smart To-Do Planner ✅

![iTask Screenshot](./screenshot.png)

iTask is a task management web app built with *React* and *Vite*. It helps users plan their day by adding, editing, completing and deleting tasks in a clean, responsive interface. Tasks are saved using *localStorage*, so your data stays even after refreshing the page.

## 🚀 Live Demo
[View the Live Project Here](https://itask-todo-app-delta.vercel.app/)

## 🎯 Why I Built This
I built iTask to practise core React concepts like state, hooks and conditional rendering, and to create a simple tool for organising my daily routine.

## ✨ Key Features
- *Add tasks:* Type a task and save it in one click.
- *Edit tasks:* Update the text of any existing task.
- *Delete tasks:* Remove tasks you no longer need.
- *Mark as complete:* Tick the checkbox and the task is shown with a strikethrough.
- *Show Finished toggle:* Hide or show completed tasks to keep your list focused.
- *Data persistence:* Uses localStorage so your tasks stay saved after a refresh.
- *Responsive design:* Works on both desktop and mobile screens.

## 🛠️ Built With
- *React.js* - UI components, state and hooks
- *Vite* - fast development server and build tool
- *Tailwind CSS* - styling and responsive layout
- *LocalStorage API* - saving tasks in the browser
- *Vercel* - deployment

## 📚 What I Learned

- Managing state with useState and side effects with useEffect
- Rendering lists and using conditional rendering (filtering finished tasks)
- Implementing full CRUD operations on front-end data
- Saving and loading data with localStorage
- Building responsive layouts with Tailwind CSS
- Deploying a Vite + React app on Vercel

## 📦 Installation
1. Clone the repo: 
```bash
git clone https://github.com/aiyu-dev/itask-todo-app
```
2. Go into the project folder:
```bash
cd itask-todo-app
```

3. Install dependencies: 
```bash
npm install
```
4. Start the dev server: 
```bash
npm run dev
```
5. Open the local URL shown in the terminal (usually
http://localhost:5173 ).
